# Agent instructions

## Documentation

Public CLI docs live in [`Kong/volcano-docs`](https://github.com/Kong/volcano-docs)
under `content/cli` and publish to https://docs.volcano.dev/cli. This
repository no longer carries published docs.

**When you add or change user-facing behavior, open a companion PR in
`Kong/volcano-docs` that updates `content/cli`**, following its format contract
(`spec/markdown-format.md`), and link the two PRs.

Keep internal or maintainer material — dev-only env vars and overrides, design
notes, implementation detail — next to the code it describes: a code comment,
or a notes/README file in the relevant package.
