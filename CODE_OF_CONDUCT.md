# Code of Conduct

## Our Pledge

We are committed to making participation in this project a welcoming and
respectful experience for everyone, regardless of age, body size, disability,
ethnicity, gender identity and expression, level of experience, nationality,
personal appearance, race, religion, sexual identity and orientation, or
technology choices.

## Expected Behavior

- Be respectful and constructive.
- Assume good intent, and ask clarifying questions before escalating.
- Keep feedback focused on the work and its impact.
- Respect maintainers' decisions about project scope, priorities, and review
  standards.

## Unacceptable Behavior

- Harassment, intimidation, or abusive language.
- Personal attacks, insults, or discriminatory comments.
- Publishing private communications or personal information without permission.
- Sustained disruption of project discussions or maintainer workflows.

## Enforcement

Maintainers may remove content, close discussions, reject contributions, or
limit participation when behavior violates this code of conduct. Enforcement
will be based on the severity and context of the behavior.

## Reporting

If you need to report a code of conduct concern, contact the project team at
`support@konghq.com`. Security issues must be reported through the process in
`SECURITY.md`, not through code of conduct reports.

This code of conduct is adapted from the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct.html.
