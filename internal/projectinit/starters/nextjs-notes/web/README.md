# Volcano Next.js Demo

Generated by `volcano init nextjs --example notes`.

## What was created

- `../package.json` for shared web/function dependencies (`@volcano.dev/sdk`, Next.js, React).
- `../volcano/migrations/001_create_notes.sql` with a per-user notes table and RLS policies.
- `../volcano/_shared/volcano-client.js` shared Volcano client helper used by both web and function code.
- `../volcano/functions/notes-summary.js` to demonstrate authenticated function invocation.
- `./next.config.js` to allow importing shared code from outside `web/`.
- A minimal Next.js app with signup/signin and per-user notes dashboard.

## Quickstart (Local)

Run commands from the project root.

1. Start local Volcano: `volcano start`
2. Deploy variables: `volcano variables deploy`
3. Apply migrations: `volcano migrations deploy --all -d app`
4. Install dependencies: `npm install`
5. Deploy the demo function: `volcano functions deploy --all`
6. Run the dev server: `npm run dev`
7. Open [http://localhost:3000](http://localhost:3000)
